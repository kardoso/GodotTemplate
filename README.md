## 📌 Objetivo da Documentação

Esses documentos foram criados para:

- manter o projeto organizado  
- padronizar o trabalho entre múltiplos membros  
- facilitar revisão de código, assets e cenas  
- reduzir conflitos e problemas de merge  
- garantir estabilidade e boa comunicação  

Se todos seguirem essas diretrizes, o projeto flui de forma mais estável e previsível.
